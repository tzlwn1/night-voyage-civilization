# 关于夜航文明

本文件由人维护，**不会被模拟引擎覆盖**。仓库首页 [README.md](../README.md) 的中部状态区块由引擎在每次推进时重写；想了解「这是什么项目」从这里读起。

## 这个仓库是什么

《夜航文明》是一个公开的自演化文明实验：用固定规则、可复现随机数与事件表，让世界在无人操作的情况下逐年运转。每一次年度结算都会留下 Markdown 编年史与 git 提交，像一本慢慢写厚的史书。

这里没有玩家手柄，也没有 AI 续写剧情。你能看到的是：人口、粮、秩序、梦境与名号如何在压力下变化，以及文明何时灭亡、后继者如何从废墟里误读前朝。

## 世界怎么自己长

1. **种子**决定创世时的地理、气候、来历与初始人口；同一种子可复现同一条时间线。
2. **每月**在引擎内按固定步骤结算气候、人口、生产、加权事件、梦境与名号。
3. **每年**写入 `chronicle/civ-XXX/YYYY.md`，并更新 `world/state.json` 与 README。
4. **GitHub Actions** 按日程对 `world/timelines.json` 里标记为活跃的分支推进若干世界年，**一年一提交**，提交信息取当年头条；提交署名统一为仓库维护者账号。

## 历史如何损耗

文明灭亡后会经历余波年与无史年，再由新文明从废墟兴起。继承时，前朝的法律、节日、地名与编年记忆会按死因、档案健康度与后继者来历被判定为**保留、神话化、篡改或失传**。

重要约定：**旧年份的编年史文件不会被改写**。后继者只能在 `chronicle/前朝/revisions/` 里留下「后世修订」，与原文对照阅读。

## tag 如何封文明

当一个文明在模拟中灭亡时，CI 会创建 Git **附注 tag**，形如：

`civ-001_1-87_name-slug`

附注里用中文写明全名、存续起止年、死因与末代人口。同名文明的逐年细节仍在 `chronicle/civ-001/annals.md` 与历年 `0001.md`… 中。

在 GitHub 仓库页打开 **Tags** 即可按文明检索「封口」记录。

## 想围观的人从哪看起

1. [README.md](../README.md) — 当前年份、人口与**最新一年编年史标题**（链到正文，自动生成）。
2. [world/index.md](../world/index.md) — 通称、自称、外号、别名链与编年链接。
3. `chronicle/civ-001/` — 从 `0000.md` 创世记起，按年往下读；若文明已亡，读 `annals.md` 与 `revisions/`。
4. **Commits** — 一年一条，信息即当年头条；灭亡年附近会出现 tag。

若你只想确认「世界有没有在动」，看 README 的「最新大事」与最近一次提交时间即可。
